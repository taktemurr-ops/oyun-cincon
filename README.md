# Çinçon · Chinchón

İspanyol destesiyle per diz, düşük puanla kapat!

İspanya ve Latin Amerika'nın remi oyunu Chinchón; 40 kartlık İspanyol destesi (kılıç, kupa, altın, sopa) kodla çizilir. 2–4 kişi, maç 100 cezaya. 100.000 üretilmiş ve doğrulanmış bölüm, 33 dil. Kart Oyunları merkez uygulamasının oyunu; ortak motor: kart-motoru.
